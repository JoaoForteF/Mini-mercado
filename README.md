# Mini-mercado

Projeto desenvolvido em Java com o objetivo de praticar os conceitos básicos de programação orientada a objetos.

## Funcionalidades

- Menu inicial para escolher o modo de acesso.
- Menu do gerente com opções de cadastro de produtos, consulta de estoque e geração de relatório.
- Menu do atendente para iniciar o expediente e realizar compras.

## Estrutura atual do projeto

- `Principal.java`: inicia o programa.
- `Mercadinho.java`: controla o menu inicial.
- `Gerente.java`: contém as opções do gerente.
- `Atendente.java`: controla o atendimento.
- `Produto.java`: representa os produtos.
- `Estoque.java`: destinada ao controle do estoque.


## Objetivo

Praticar a criação de classes, métodos, construtores, objetos e estruturas de controle em Java.

## Pontos a serem implementados

- Implementar o encapsulamento dos atributos.
- Validar os dados dos produtos.
- Implementar o controle de estoque.
- Corrigir a lógica de compras e cálculo do total.
- Melhorar o funcionamento dos menus.
- Implementar a geração de relatórios.
- Integrar o sistema ao Google Sheets para armazenar os dados.
